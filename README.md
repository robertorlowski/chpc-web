# chpc-web

Sterowanie pompą ciepła CHPC z chmury, dane z fotowoltaiki i monitoring hydroforu: serwer (Node.js), aplikacja WWW (React) i firmware sterowników (`devices/`).

**Dokumentacja:** [docs/README.md](docs/README.md) — opis systemu, schemat i dokumentacja każdego modułu (opis biznesowy, zasada działania, dokumentacja techniczna).

```bash
npm install
npm run local    # lokalna baza, serwer i aplikacja
```
